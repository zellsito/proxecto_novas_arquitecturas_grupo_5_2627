
# Daniel Pérez — Implementación de la capa de sensores virtuales de BunkerOS.

## Tecnologías
- Node-RED
- GitHub Codespaces
- MQTT
- Broker público Mosquitto

## Funcionalidades
- Simulación de los sensores del refugio.
- Publicación de telemetría por MQTT.
- Recepción y validación de mensajes.
- Integración con el dashboard del equipo.
